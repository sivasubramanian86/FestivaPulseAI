## Overview

**FestivaPulseAI** is an autonomous event resilience copilot and day-of-event operating system for **Weddings, Birthdays, and Community Events**.
It replaces static checklists with real-time shock absorption, 3-way comparative recovery strategies, FSSAI-compliant surplus food rescue, and an on-screen live GenAI X-Ray Telemetry Inspector.

---

## Core Differentiators

1. **AI Proposes; Deterministic Engine Verifies:** Pure Python domain functions compute all money, attendance, food inventory, venue capacity, and timeline dependencies. The LLM is never the source of truth for arithmetic.
2. **Rescue Studio (Comparative Recovery):** Shocks produce 3 structured alternatives: (1) Lowest Cost, (2) Best Experience, (3) Lowest Disruption, or a certified "NOT FEASIBLE" refusal.
3. **FestivaFoodGuard (FSSAI Zero-Waste Engine):** Real-time category-level food sufficiency radar (veg, vegan, jain, allergies) and certified NGO food-rescue manifests with ESG carbon prevention metrics.
4. **GenAI X-Ray Telemetry Drawer:** Persistent split-screen inspector proving dynamic, non-hardcoded generation with live prompts, JSON schemas, and latency counters.
5. **Strict Repository Size (< 10 MB):** Procedural SVG schematics and zero tracked binary media keep repository footprint strictly `< 1.5 MB`.
